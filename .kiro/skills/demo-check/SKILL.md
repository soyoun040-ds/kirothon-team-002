# 데모 전 점검

심사 전에 데모가 깨지지 않는지 아래 순서로 확인하고, 결과를 표로 보고한다.

1. `npm run build` 실행 → 오류가 있으면 원인과 수정 방법 보고
2. `npm run dev`로 서버 실행
3. `.kiro/steering/product.md`의 **데모 시나리오**를 순서대로 따라가며 화면 확인
   (Playwright MCP가 연결돼 있으면 브라우저를 직접 열어 클릭)
4. 브라우저 콘솔에 빨간 에러가 있는지 확인
5. 코드에 비밀 키가 직접 적혀 있지 않은지 검색 (`.env.local` 외)

## 보고 형식

| 항목 | 결과 | 문제 / 조치 |
|---|---|---|
| 빌드 | ✅ / ❌ | |
| 데모 1단계 | ✅ / ❌ | |
| ... | | |
| 콘솔 에러 | ✅ / ❌ | |
| 비밀 키 노출 | ✅ / ❌ | |

문제가 있으면 **고치지 말고 먼저 보고**한 뒤 사용자 승인을 받고 수정한다.
